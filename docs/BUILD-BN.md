# ফোনে চালানোর জন্য APK বানানো (v3 — BlackBox ইঞ্জিনসহ)

## সবচেয়ে সহজ পদ্ধতি: GitHub Actions

1. এই ফোল্ডারের সব ফাইল GitHub-এ নতুন repository-তে push করো।
   (zip ফাইলটা নয় — ফোল্ডারের ভেতরের ফাইলগুলো।)
2. **Actions** ট্যাব → **Build APK** → **Run workflow** (push করলেই অটো চলে)।
3. ⚠️ প্রথম বিল্ডে **১৫–২৫ মিনিট** লাগতে পারে — NDK ডাউনলোড হয় বলে।
4. শেষ হলে **Artifacts** থেকে `app-debug` ডাউনলোড করো → ভেতরে `app-debug.apk`।
5. APK ফোনে নিয়ে ইনস্টল করো। "Unknown apps" অনুমতি চাইলে Allow দাও।

## প্রথম চালুতে

- অ্যাপ খুললে BlackBox ইঞ্জিন নিজে init হবে — কয়েক সেকেন্ড লাগতে পারে।
- "সব অ্যাপ" ট্যাব থেকে যেকোনো অ্যাপে **ক্লোন** চাপো → ক্লোন ট্যাবে **চালু করুন**।
- সব অ্যাপ সমানভাবে চলবে না — সহজ অ্যাপ (ক্যালকুলেটর, নোট) দিয়ে আগে টেস্ট করো।
- সমস্যা হলে logcat-এ `BlackBox` / `ClonerApp` ট্যাগ দেখো।

## ইঞ্জিন সম্পর্কে

- `blackbox/` ফোল্ডারে ALEX5402/NewBlackbox ফর্কের Bcore, black-reflection,
  compiler মডিউল আছে (Apache 2.0 লাইসেন্স)।
- `BlackBoxCloneEngine.kt` এই ইঞ্জিনকে অ্যাপের সাথে যুক্ত করে।
- targetSdk 28 রাখা হয়েছে ইচ্ছা করে — ফর্কের সুপারিশ অনুযায়ী।
